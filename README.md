# 🎮 Video Games SQL Analytics Project

## About
A SQL analytics project where I analyse video game data to find insights
about ratings, sales, platforms, genres and developers.

## Tools Used
- SQL (SQLite)
- DB Browser for SQLite

## Queries
1. **Top 5 highest rated games** - Finding the best games by rating
2. **Games per platform** - Which platform has the most games?
3. **Total sales per developer** - Which developer has sold the most?
4. **Highest rated game per genre** - Best game in each genre
5. **International games** - Games developed outside the USA

## What I Learned
- Writing SQL queries independently from scratch
- Using aggregate functions like COUNT, SUM and MAX
- Filtering and grouping data to find meaningful insights
- Analysing real world data across multiple categories
